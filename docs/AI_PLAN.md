# Текущий AI-план

Статус: готов к запуску

Roadmap: `ET-01.2 — Минимальная тестовая стратегия`

SPEC: `../specs/system.spec.md` (`FR-002`, `FR-006`, `AC-002`, `AC-005`,
`AC-007`)

## Цель

Добавить минимальный воспроизводимый набор автоматических тестов для чистой
математической модели круговой диаграммы и контрактов публикации RU/UK-уроков.

## Предусловие

`ET-01.1` завершён: `npm run check`, `npm run lint` и `npm run build` проходят.

## Область

- выбрать один минимальный test runner, совместимый с Astro/Vite/TypeScript;
- отделить чистую математическую модель круговой диаграммы от React-компонента
  без изменения наблюдаемого поведения;
- покрыть обычные, граничные и вырожденные вычисления модели;
- добавить проверку парности опубликованных RU/UK-уроков;
- добавить проверку уникальности идентификаторов опубликованных уроков;
- добавить одну штатную команду test и связать тесты с требованиями SPEC.

## Вне области

- проверка и исправление соответствия каталога опубликованным урокам (`ET-02`);
- browser/E2E-тесты, визуальная переработка и новые интерактивные инструменты;
- обновление уязвимых зависимостей и deploy;
- рефакторинг всего legacy React-слоя.

## Шаги

1. Проверить доступные test APIs текущего Astro/Vite-стека и выбрать минимальную
   зависимость без второго build pipeline.
2. Определить чистый контракт входов/выходов круговой модели и вынести его из
   `CircularDiagram.tsx` с сохранением UI.
3. Написать unit-тесты обычных, предельных и сингулярных значений.
4. Написать contract-тесты парности и уникальности фактических опубликованных
   MDX/frontmatter.
5. Выполнить test, check, lint, build и `git diff --check`; провести review и
   обновить фактический статус.

## Критерии приёмки

- test command выполняется без интерактивной установки;
- математические тесты проверяют нормальный расчёт, границы и сингулярность;
- парность `ru`/`uk` и уникальность опубликованных идентификаторов проверяются;
- все обязательные тесты завершаются успешно без skip/disable;
- `check`, `lint` и `build` продолжают проходить;
- один commit содержит только этот логический этап.

## Откат

Один commit этапа можно отменить без миграции данных или изменения production.
