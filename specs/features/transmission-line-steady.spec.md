# Установившийся режим длинной линии

Требования Stage 9 из ElectroTutor Master Prompt v2, § 8 и § 24.

- LINE-AC-001. Для однородной линии при f > 0 ядро принимает распределённые параметры R′ и G′ ≥ 0, L′ и C′ > 0 в SI и длину ℓ ≥ 0. Конвенция фазоров eʲωᵗ, положительный ток направлен к нагрузке. z′ = R′ + jωL′, y′ = G′ + jωC′, γ = √(z′y′) с неотрицательными действительной и мнимой частями, Zc = √(z′/y′) с положительной действительной частью.
- LINE-AC-002. Матрица передаёт вектор [U, I] от нагрузки к входу. A = D = cosh(γℓ), B = Zc sinh(γℓ), C = sinh(γℓ)/Zc. При ℓ = 0 матрица единичная. Поддержаны линии с потерями и без потерь и проверяется взаимность. Некорректный либо численно непредставимый ввод получает явную диагностику.
- LINE-AC-003. Входное сопротивление вычисляется для согласованного, произвольного комплексного, короткозамкнутого и разомкнутого окончания. Обрыв имеет отдельное представление, конечные значения и физические полюса различаются. Проверки включают четверть и половину волны, независимый расчёт с потерями и проверку сопротивления через отражение.

Конвенции и контрольные формулы сверяются с [MIT Electromagnetic Fields and Energy, гл. 14](https://ocw.mit.edu/courses/res-6-001-electromagnetic-fields-and-energy-spring-2008/pages/chapter-14/) и [Purdue ECE 350, разделы 6 и 11](https://engineering.purdue.edu/wcchew/ece604f19/Supplementary%20Texts/ee350X-notes.pdf).
