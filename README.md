# ElectroTutor

На главной RU/UK восемь демонстраций со схемой, формулами и расчётным графиком. Под примерами пять ссылок на лаборатории по несимметричной звезде, длинным линиям, сопромату, аппроксимации контура и круговой диаграмме. Доска открывается отдельно из меню. Учебник и решения доступны из подвала. Модели и границы экспериментов описаны в [дорожной карте](docs/ROADMAP.md).

В разделе «Лаборатории» каждый самостоятельный опыт открывается нажатием в любой точке его карточки. Ссылка над заголовком возвращает в каталог того же языка. В опыте LC начальная цепь имеет вид a–L–C–b. Выберите элемент в палитре или перетащите его на маркер. Знак «+» вставляет его в разрыв, «∥» подключает параллельно подсвеченному участку. Щелчок по эквивалентному элементу раскрывает исходный участок.

В опытах A, B и D кнопка «Провода» открывает действия для выбранного соединения. Намеренный разрыв виден пунктиром и сохраняется с рабочей схемой. Удаление последовательного элемента может восстановить проводник. Для целой параллельной ветви редактор показывает список удаляемых элементов. Очистка подтверждается и отменяется одним Undo. [Проверки редактора](docs/TESTING.md#et-2511-003--обратимые-операции-с-проводами-и-ветвями).

В переходном опыте A у секции две пары выводов. На выходе можно задать согласованную нагрузку, идеальное КЗ или холостой ход. Вход и выход отображаются на схеме, а результаты выбранной секции включают эпюры U и I. [Проверки переходной линии](docs/TESTING.md#et-2511-004--четырёхклеммная-переходная-линия).

Релиз ET-UI-010 включает презентационную главную и три учебных раздела в RU/UK. Состояние публикации приведено в STAGES.


## Параллельное подключение в общем редакторе

1. Перетащите компонент из палитры на существующий элемент либо выберите компонент и «Параллельно участку».
2. Для группы или всей ветви выберите два граничных электрических узла на холсте или в списках. При нескольких вариантах явно выберите участок.
3. Проверьте подсветку и пунктирный маршрут, нажмите «Подключить параллельно». Действие отменяется одним Undo; JSON сохраняет исходные компоненты и новые соединения.
4. Отдельно раскройте «Эквивалентная RLC-модель». Укажите модель расчёта и наличие взаимной связи. Это read-only представление, исходные компоненты продолжают редактироваться.

Состояние локальной проверки и публикации этой функции: ET-CE-PARALLEL-001 в [STAGES](docs/STAGES.md). Security-замена picomatch, полный verify и CI прошли; функция слита в main и проверена на Cloudflare и GitHub Pages. Точная выпущенная ревизия и evidence — в STAGES.

## Навигация в полной сборке

Мастер-приёмка четырёх лабораторий выполнена на Cloudflare и GitHub Pages из `ff267aa`. Публичные адреса, контрольные суммы и сценарии на пяти размерах экрана приведены в [Phase 6–8](docs/evidence/universal-labs-v3-phase6-8.md).

Главное действие открывает каталог лабораторий. В общем каталоге и каталоге микролабораторий иллюстрированная карточка целиком ведёт на страницу опыта. Поиск и фильтр по направлениям помогают выбрать лабораторию. Старые закладки на микролаборатории продолжают открывать нужный расчёт. Учебник и решения доступны отдельно. В лаборатории длинной линии параметры открываются по выбору объекта на схеме. В актуальном опыте «Переходные процессы в длинной линии» закреплённая панель управляет воспроизведением на схеме и в результатах. В прежней сетевой модели плеер доступен по ссылке «Управление опытом». Можно скачать измерения в JSON или CSV и эпюру напряжения в SVG. Неподключённые компоненты можно оставить на поле и подключить позже. Координаты размещённых компонентов переходного опыта закреплены. Новые элементы можно перетащить из палитры, а выводы выбираются командой переподключения. R, L, C, ключи и диоды Шокли участвуют в расчёте в пределах поддерживаемой топологии. Локальный черновик восстанавливается после обновления страницы.

Учебный сайт работает в RU/UK и использует светлое оформление. Прежний RU MVP и полный профиль разработки доступны как отдельные сборки. Состав проверенного артефакта приведён в [STAGES](docs/STAGES.md).

## Что доступно в полной сборке

Полный режим содержит общий каталог тем и инструментов на русском и украинском,
опубликованный учебник и дополнительные практикумы. Среди интерактивов есть
несимметричная звезда с переключаемой нейтралью, переходные процессы в длинной линии,
разложение Фурье, круговые диаграммы и расчёт балок. Наличие карточки в каталоге
само по себе не означает, что для темы опубликован урок.

Кабинет и связанные сценарии доступны с локальным backend. Публичный MVP
ограничен учебным маршрутом без кабинета, расписания и платежей. Открытые
вопросы production IAM, видеосвязи, новых лабораторий и развития продукта
ведутся в [STAGES](docs/STAGES.md) и [ROADMAP](docs/ROADMAP.md).

## Архитектура

- Astro генерирует статические страницы из Content Collections и MDX.
  React islands на TypeScript обеспечивают интерактивы. Обе сборки используют
  общие источники уроков и учебной навигации.
- Учебные расчёты выполняются в браузере. Для переходных процессов также
  используется Rust/WASM из `transient-core/`.
- Отдельный локальный FastAPI работает с PostgreSQL через SQLAlchemy и
  Alembic. Аутентификация использует Keycloak OIDC с PKCE. Кабинет обращается
  к API, а для локальных уведомлений предусмотрен отдельный worker.
  Публичный учебный артефакт работает без этих сервисов.

## Установка и запуск

Для фронтенда нужны Node.js `>=22.23.4` и pnpm `11.23.0` из
[package.json](package.json). На Windows при блокировке PowerShell-обёртки
используйте `pnpm.cmd` либо `corepack pnpm` с закреплённой версией. pnpm автоматически загружает
закреплённый в проекте Node 22.23.4 для запуска скриптов.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Откройте `http://127.0.0.1:4321/ru/`. `pnpm dev` по умолчанию открывает
полный режим. `pnpm build` собирает публичный учебный профиль RU/UK.
Локальный редактор схем доступен по `/ru/interactive/circuit-editor/` и `/uk/interactive/circuit-editor/`. Его JSON можно открыть в лаборатории длинных линий через её штатную панель файлов. В разделе «Универсальный редактор схем» лаборатории можно собрать схему, выполнить расчёт и увидеть показания на линии. Адаптер поддерживает цепочку секций с одним источником напряжения или тока, промежуточные ветви и последовательные и параллельные концевые нагрузки. Лаборатория открывает архивы line-v2–v5 в универсальном редакторе. Панели лаборатории дают доступ к параметрам опыта, измерениям, исходным штрихам и экспорту результатов.

Лаборатории длинной линии открывают переходный и синусоидальный режимы в общем CircuitEditor. Реактивный LC-граф рассчитывает Z(s), X(ω), формы Фостера и Кауэра и электрически эквивалентные упрощения. Лаборатория электрических сетей доступна по `/ru/interactive/power-system/` и `/uk/interactive/power-system/`.

В сетевой лаборатории можно открыть радиальный фидер или кольцо, импортировать документ сети, либо собрать свою схему из шин и физических устройств. Паспортные типы импортируются отдельно как каталог JSON. Схемы замещения и источники данных доступны в инспекторе оборудования. Расчёт по Ybus показывает режим на однолинейной схеме. Простое кольцо также можно рассчитать учебным методом и сравнить с Ybus.

Команды `pnpm build:mvp` и `pnpm build:full` собирают прежний MVP и профиль разработки соответственно.
Сборка помещает артефакт в `dist/` по умолчанию. Публичные параметры
`SITE_URL`, `BASE_PATH` и `PUBLIC_API_ORIGIN` описаны в
[.env.example](.env.example).

### Backend и локальный вход

Нужны Python 3.12, uv 0.12.3 и Docker Compose. Для локального dev-стека
с отдельной dev-БД:

```bash
pnpm backend:bootstrap
pnpm backend:dev
pnpm backend:doctor
pnpm backend:smoke
pnpm backend:stop
```

`backend:dev` применяет миграции Alembic и запускает API на
`127.0.0.1:8000`. `backend:stop` сохраняет тома. На машине с сохранённой
старой БД сначала используйте процедуру диагностики каталога и изолированный
контур из [Backend DX](docs/project-context.md#backend-dx-delta).

Для входа задайте `ET_KEYCLOAK_ADMIN_PASSWORD` и `ET_DEV_TEST_PASSWORD`
локально. `pnpm backend:idp:dev` подготавливает DEV realm и тестовые
учётные записи. Проверьте `/ru/account/` или `/uk/account/` в полном
локальном режиме. Условия запуска обычного и изолированного auth E2E
описаны в [TESTING](docs/TESTING.md).

## Проверки

```bash
pnpm check:context
pnpm check:locales
pnpm check
pnpm lint
pnpm test
pnpm test:e2e:install
pnpm verify:full
```

`verify:full` запускает статические, браузерные и сборочные проверки.
Отдельно `pnpm check:base-path` проверяет сборку под префиксом репозитория,
а `pnpm backend:check` проверяет backend. Матрица тестов, требования к
тестовой БД и текущий пробел визуальных эталонов Linux описаны в
[TESTING](docs/TESTING.md).

Для проверки лаборатории длинной линии запустите `pnpm eval:labs --check-rejection`.
Команда соберёт education, откроет RU desktop и UK mobile в Chromium и сохранит
JSON, снимки и traces. [Как воспроизвести и принять результат](docs/TESTING.md#et-labr-001--браузерный-eval-длинной-линии).
Команда `pnpm eval:topology` проверяет команды ядра по [JSON-фикстуре и электрическим инвариантам](docs/TESTING.md#et-labr-002--топологическое-ядро).
Ссылка «Топологический режим» под свободным редактором открывает SVG-площадку с картой E3.
[Проверка компоновки, мыши и касаний](docs/TESTING.md#et-labr-003--svg-компоновка).
Пункт «Переходные процессы в длинных линиях» в каталоге открывает лабораторию A
по маршруту `/{ru,uk}/interactive/transmission-line/experiment/`.
[Приёмка схемы, выбранной секции и архива](docs/TESTING.md#et-labr-004--лаборатория-a).
Пункт «Длинная линия в синусоидальном режиме» открывает лабораторию B
по маршруту `/{ru,uk}/interactive/transmission-line-steady/experiment/`.
[Приёмка синусоидального опыта](docs/TESTING.md#et-labr-005--лаборатория-b).
Пункт «LC-двухполюсник» открывает лабораторию D по маршруту
`/{ru,uk}/interactive/reactive-two-port-graph/experiment/`.
[Приёмка резонансов, переноса катушки и архива](docs/TESTING.md#et-labr-006--лаборатория-d).
Пункт «Длинная линия с переменными параметрами» открывает лабораторию C по
маршруту `/{ru,uk}/interactive/transmission-line-variable/`. Выберите провод на
схеме для вставки резистора, затем запустите импульс и сравните эпюры и баланс.
[Приёмка профилей и расчёта](docs/TESTING.md#et-labr-007b--экспериментальная-линия-c).
Карточка «Базисные разложения сигнала и контура»
открывает лабораторию E по маршруту `/{ru,uk}/interactive/fourier/bases/`.
На одной сетке можно сравнить девять базисов, посмотреть выбранный вклад и
сохранить опыт в JSON. [Приёмка лаборатории E](docs/TESTING.md#et-labr-008--лаборатория-e).
Карточка «Аппроксимация контура» открывает
лабораторию F по `/{ru,uk}/interactive/fourier/polygon-motion/`. Нарисуйте контур
или откройте локальный SVG, выберите круговые эпициклы, треугольные или квадратные движения. Старый адрес эпициклов открывает круговой метод.
[Приёмка лаборатории F](docs/TESTING.md#et-labr-009--лаборатория-f).

Отдельная карточка «Качение тела по заданному следу» открывает лабораторию G
по `/{ru,uk}/interactive/rolling/`. Нарисуйте открытый след, нажмите «Пуск»
и проверьте качение и точку контакта. Из готового опыта можно выгрузить OBJ и JSON.
Численные эталоны воспроизводятся командой `node scripts/rolling-feasibility.mjs --eval`.
[Приёмка лаборатории G](docs/TESTING.md#et-labr-010b--лаборатория-g).
