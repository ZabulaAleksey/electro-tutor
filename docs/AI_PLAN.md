# Текущий AI-план

Статус: готов к выполнению

Roadmap: `ET-04 — Browser-проверка интерактива`

SPEC: `../specs/system.spec.md`; публикационный контракт —
`../specs/features/lesson-publishing.spec.md`.

## Цель

Проверить в реальном браузере ключевые пользовательские потоки, которые нельзя
надёжно подтвердить unit/contract-тестами: восстановление URL-состояния,
локализованную навигацию, тему, клавиатуру, accessibility и мобильный layout.

## Предусловие

`ET-01` и `ET-02` завершены: test/check/lint/build проходят, публикация уроков
выводится из Content Collection manifest, а route поддерживает optional island.

## Область

- добавить минимальный browser test runner и воспроизводимую конфигурацию;
- проверить RU/UK-переход урока с сохранением query/hash;
- проверить восстановление параметров круговой диаграммы из URL;
- проверить переключение и сохранение темы;
- проверить клавиатурную навигацию, основные accessibility-инварианты и
  мобильный layout.

## Вне области

- создание новых учебных материалов без выбора пользователя (`ET-03`);
- редизайн страниц и новые интерактивные инструменты;
- аккаунты, платежи, booking и production deploy.

## Шаги

1. Настроить browser runner и smoke-проверки основных RU/UK-маршрутов.
2. Покрыть query/hash и смену языка на интерактивных страницах.
3. Покрыть тему, клавиатуру, accessibility и мобильный viewport.
4. Повторить test, check, lint, build и browser suite.

## Критерии приёмки

- RU/UK-страницы и существующий интерактив открываются без browser errors;
- query/hash сохраняются при смене языка и восстанавливают состояние;
- тема сохраняется после навигации/перезагрузки;
- основные элементы доступны с клавиатуры и имеют корректные accessible names;
- критические страницы не получают горизонтальную прокрутку на мобильном;
- test/check/lint/build/browser проходят без skip/disable.

## Откат

Каждый подэтап оформляется отдельным commit и может быть отменён без миграции
данных или изменения production.
