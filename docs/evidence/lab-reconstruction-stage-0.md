## Инвентаризация пользователя и реализации

Префикс локализованных адресов — `/{ru,uk}/interactive/`. Каталог — `/{ru,uk}/interactive/`.
Исходные Astro-страницы монтируют React islands, вычисления работают в браузере.
Публичные лаборатории входят в профиль education с RU/UK, локальными Worker/WASM
и статическим режимом. Кабинет, API и БД принадлежат другим контурам проекта.

| Доступный маршрут | Найденные компоненты и расчёт | Границы исходной реализации |
| --- | --- | --- |
| `transmission-line/` | TransmissionNetworkLab → CircuitEditor → line archive/circuit adapter → network Worker → эпюры. Есть также отдельное ядро Rust/WASM для удерживаемых моделей. | Один маршрут с редактором, графиками и воспроизведением. Стартовая модель `STARTER_NETWORK`: 100 В, внутренние 50 Ω, открытый ключ, TL1 1000 км / 50 Ω, нагрузка 50 Ω, 20 мс. Разомкнутый ключ не имеет стартового события. Круг со стрелкой на снимке относится к ЭДС в данных, для типа источника проверять модель. Активна ссылка «Синусоидальный режим». Установленные компоненты заблокированы в этом режиме, провод/узел доступны как команды. |
| `transmission-line-steady/` | SteadyLineLab → общий редактор → steady circuit mode → RLGC/ABCD/phasors. Есть численная проверка фазоров, позиции x и расчёта от графа. | Прямые параметры однородной модели и параметры из редактора входят разными путями. Редактор допускает ЭДС, TL, R/L/C. Преобразование из общего графа ограничено текущим типом источника, путём и представлением потерь. |
| `reactive-two-port-graph/`, `reactive-two-port/` | Общий CircuitEditor в LC-режиме, driving-point reactance по графу, отдельное бинарное LC-дерево и рациональный Z(s), Foster/Cauer. | Сохранить обе существующие точки входа и расчётные контракты. Новая модель выбора слотов и расширение автокомпоновки нужны только в согласованном LC-режиме. |
| `power-system/`, `circuit-editor/` | Общие документы и редактор, электрические сети с радиальными/кольцевыми/Ybus методами, отдельный свободный редактор. | Регрессии этих режимов существенны. Для сетей предел редактора 128 шин/256 устройств и предел AC 64/192 относятся к другой модели и не определяют допустимость 200 элементов E4. |
| `fourier/` | FourierLab, DFT и контур, настройки гармоник и эпициклы, Haar/DCT-II/Walsh, готовые фигуры и ограниченный custom basis QR. | Геометрические пресеты — формы входа. Ещё нужны два раздельных метода/продуктовых пути по новой SPEC, независимые эталоны дополнительных базисов и аппроксимации. |
| `transmission-line-reference/`, общие визуализации/эксперименты | Legacy/reference route, `EngineeringPlot`, библиотеки УГО и графиков, локальные демонстрации. | Ссылки и учебные материалы используются как проверяемая исходная поверхность. Общий расчёт C и обратная задача 3D G не обнаружены. |

Общий код: топология и netlist `src/circuit/topology.ts`, геометрия `drawing.ts`,
`routing` и Worker, режимы `editor-mode.ts`, версия документа `document.ts`,
`parallel-regions.ts` и `parallel-attachment.ts`. Существующий resolver получает
границы от пользователя и может включать отводы в найденный регион.
Строгому непрерывному ряду понадобится свой составной критерий поверх общей графовой модели.
При всех допустимых интервалах на цепочке из N звеньев возникает N(N+1)/2 вариантов
до геометрических сторон. Нужна контекстная выдача без потери достижимости и перегрузки SVG.

Два канала статической доставки: GitHub Pages c base `/electro-tutor/`, Cloudflare
c base `/`. В существующем `.github/workflows/pages.yml` проверка основной ветки
через `verify:full` предшествует deploy. Текущие CD-гейты и безопасные ограничения
публичного профиля остаются основой будущего harness.
Релевантные ограничения браузера: бюджет Worker/structured clone, различие mouse и touch,
размеры SVG/hit-target при масштабировании, ограниченный безопасный импорт данных, WebGL
context loss и вариативность устройств. Приёмка физического мобильного устройства запланирована
для интерактивных стадий, а текущие снимки получены в эмуляции Chromium.

## Источники и ограничения

- Промпт прочитан через Google Docs API, таб `t.0`. В проверенных структурах этого таба
  нет вложенных/позиционированных рисунков и ссылок на них. В Git обнаружены прежние
  свидетельства сверки УГО и скриншоты приложения. Их недостаточно для точной разметки
  схем 1–10 и 1–14 или идентификации зачёркнутого элемента. Зависимость хранится в STAGES
  как LABR-UA-REF.
- Принятые `LINE-UX-035`, `LINE-UX-037/039/040` и тест навигации B из A расходятся
  с новой постановкой. Аналогично CE-008/CE-022 проверяют существующие жесты.
  Разрешение конфликтов описано в ADR-062 и ADR-063.
- Росстандарт указывает действующий статус 2.721-74, 2.723-68, 2.728-74, 2.755-87.
  Проверка формы, выводов и направлений каждого знака и профиль применения остаются
  гейтом этапа 3. Существующий набор УГО и ориентиры собраны в [ADR-057](../DECISIONS.md#adr-057--геометрия-схемы-и-концевой-диод).
- В этом запуске 10 из 10 проверенных публичных RU URL вернули HTTP 200. Это пять
  адресов A, B, LC graph, сети и Fourier на [основном домене](https://electrotutor.org/ru/interactive/)
  и [GitHub Pages](https://zabulaaleksey.github.io/electro-tutor/ru/interactive/).
  SHA-256 восьми JS островов A/B/LC/сети совпал с опубликованным
  [receipt Phase 6–8](universal-labs-v3-phase6-8.md#публичные-лаборатории-и-артефакты).
  Сравнение ограничено выбранными бандлами и URL. Историческую полную hosted-приёмку
  94 сценариев на хост в текущем запуске не повторяли.

## Воспроизведение baseline

В PowerShell из корня ElectroTutor:
```powershell
corepack pnpm install --frozen-lockfile
corepack pnpm build
$env:ASTRO_PREVIEW_BACKGROUND = '0'
corepack pnpm preview --host 127.0.0.1 --port 4327
```

1. Открыть `http://127.0.0.1:4327/ru/interactive/transmission-line/` на ПК или
   в Chromium touch viewport 390 × 844. Видны источник, разомкнутый ключ, TL1 и резистор.
   Открыть «Управление опытом», нажать «Пуск»/«Стоп». Доступны четыре графика и сброс
   времени к нулю. Не подменять этот опыт стартовой схемой будущего этапа 4.
2. Для численного контрольного примера нажать «Синусоидальный режим», выбрать
   «Окончание → согласованная нагрузка». Модуль обратной волны U равен 0 В.
   В исходном режиме «Схема» в начале линии ожидаются 50 В падающей,
   16⅔ В отражённой и 33⅓ В суммарной волны. При `x=500 км` суммарный модуль
   66⅔ В. Эти числа и обновление фазоров проверены принятым E2E.
3. Открыть LC graph, нажать на полюс: отображается `|X| → ∞`.
   Проверить Fourier, переключив «Базис» на DCT-II: реконструкция остаётся, вращающиеся
   векторы исчезают. По окончании закрыть локальный preview через Ctrl+C.

Ручные действия доступны также на опубликованных исходных маршрутах. Автоматический
живой прогон отдельно проверил реальные Worker/WASM, координату и фазоры, LC и Fourier.
Физический телефон в этом запуске не использовался.
