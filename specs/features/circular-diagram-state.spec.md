# SPEC: Версионированный URL/state круговой диаграммы

Статус: Действует

Версия: 1.0

## 1. Цель и область

Интерактив круговой диаграммы должен принимать недоверенные query-параметры без
обхода математических инвариантов и создавать воспроизводимую share-ссылку.
Контракт относится к `/ru/interactive/` и `/uk/interactive/`; backend,
аккаунты и сохранённые presets не входят в этап.

## 2. Схема версии 1

Ключ `v=1` обязателен в каноническом URL. Порядок полей фиксирован:
`v`, `i0m`, `i0a`, `ikm`, `ika`, `zm`, `za`, `phi`, `r`.

| Поле | Смысл | Default | Допустимый диапазон |
|---|---|---:|---:|
| `i0m` | модуль тока холостого хода, А | 1.5 | 0…1000 |
| `i0a` | угол тока холостого хода, ° | -18 | -180…180 |
| `ikm` | модуль тока короткого замыкания, А | 8 | 0…1000 |
| `ika` | угол тока короткого замыкания, ° | -55 | -180…180 |
| `zm` | модуль выходного сопротивления, Ом | 4 | 0.01…1000000 |
| `za` | угол выходного сопротивления, ° | 35 | -90…90 |
| `phi` | угол нагрузки, ° | 25 | -90…90 |
| `r` | положение нагрузки, % | 43 | 0…100 |

Числа сериализуются в краткой десятичной форме; `-0` канонизируется как `0`.
Максимальная длина query без начального `?` — 1024 символа.

## 3. Требования

### CDS-FR-001 Pure pipeline

Чтение выполняется чистым pipeline `parse → validate → normalize → canonicalize`.
React-компонент и математическая модель получают только типизированное состояние.

### CDS-FR-002 Недоверенный URL

`NaN`, `Infinity`, пустые, нечисловые, отрицательные там, где они запрещены,
выходящие за диапазон значения, duplicate known keys, duplicate `v`, неизвестная
версия и oversized query не должны попадать в модель. Весь state восстанавливается
к defaults, URL канонизируется, пользователь видит локализованное сообщение.

Неизвестные параметры не влияют на state и удаляются из канонического URL.
Отсутствующие известные поля получают defaults.

### CDS-FR-003 Совместимость

Допустимая ссылка прежнего формата без `v` читается как legacy version 0 и
детерминированно мигрирует в `v=1`. Query и hash сохраняются при переходе между
локалями по системной SPEC.

### CDS-FR-004 История браузера

Частые изменения range-control используют `history.replaceState`. Завершённое
редактирование числового поля является смысловым переходом и использует
`history.pushState`. `popstate`, back, forward и reload восстанавливают UI и
модель из канонического URL.

### CDS-NFR-001 Детерминизм

Канонизация идемпотентна: повторный parse/serialize не меняет query. Одинаковое
состояние создаёт одинаковую строку независимо от порядка входных параметров.

## 4. Критерии приёмки

- CDS-AC-001: valid version 1 и legacy share-links воспроизводят состояние;
- CDS-AC-002: boundary values принимаются, значения вне диапазона безопасно
  восстанавливают defaults и не создают `NaN`/`Infinity` в модели или SVG;
- CDS-AC-003: duplicate keys, unknown version, malformed/encoded и oversized
  query имеют детерминированный safe fallback;
- CDS-AC-004: canonical serialization стабильна и идемпотентна;
- CDS-AC-005: UI, URL, back/forward, language switch и reload согласованы в
  живом Chromium E2E;
- CDS-AC-006: `pnpm check`, `pnpm lint`, `pnpm test`, `pnpm build`, lesson audit
  и `pnpm test:e2e` проходят.
