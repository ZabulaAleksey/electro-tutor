# Несимметричная звезда с нейтралью

Статус: утверждённый contract для отдельного учебного интерактива.

## Проверяемые требования

- `INT-004`: RU/UK маршрут из раздела «Интерактив», локальный симметричный
  источник ABC с редактируемым `U_phase = 230 V` по умолчанию.
- `INT-005`: чистый расчёт для ideal/finite/open neutral по формулам ниже,
  включая `I_N` в направлении n → N и численную защиту.
- `INT-006`: единое состояние R/X и |Z|/φ каждой фазы и нейтрали,
  немедленная двусторонняя синхронизация и drag A/B/C.
- `INT-007`: плоскость Z слева и совмещённая топографическая диаграмма
  напряжений/токов справа с подписями, независимыми масштабами В и А,
  числовыми результатами и мобильным layout без page overflow.
- `INT-008`: четыре локальных presets и пользовательские диагностические
  состояния без NaN/Infinity.

## Пользовательский путь

Раздел «Интерактив» ведёт на локализованную страницу звезды. Пользователь меняет
`U_phase`, комплексные `Z_A`, `Z_B`, `Z_C` и режим нейтрали, наблюдая пересчёт
потенциала нейтрали, фазных напряжений и токов без сетевых запросов. Значения
фазных сопротивлений можно менять численно в формах R/X и |Z|/φ или перетаскиванием
подписанных точек A/B/C на правой полуплоскости Z (R ≥ 0). Для конечной нейтрали
`Z_N` доступен в обеих численных формах. Поля остаются доступной альтернативой drag.

## Расчёт

Симметричный источник ABC: `E_A = U_phase ∠ 0°`, `E_B = U_phase ∠ -120°`,
`E_C = U_phase ∠ +120°`; default `U_phase = 230 V`. Потенциал `N = 0`.
Для finite nonzero neutral `U_nN = Σ(E_k/Z_k)/(Σ(1/Z_k) + 1/Z_N)`;
для open neutral убрать `1/Z_N`, а для ideal neutral принять `U_nN = 0`
без деления на нуль. `U_k = E_k - U_nN`, `I_k = U_k/Z_k`,
`I_N = I_A + I_B + I_C` (направление n → N).

Нулевое или почти нулевое фазное сопротивление, вырожденный знаменатель и
непредставимый численно результат дают понятное диагностическое состояние без
NaN/Infinity в UI. Ввод конечных чисел ограничен безопасным диапазоном. Числа
хранятся без округления, форматируются только при показе.

## Визуализация и приёмка

- Слева SVG плоскости Z только для R ≥ 0 с осями Re/Im в Ω; справа единый SVG
  напряжений и токов. Числовые настройки идут после диаграмм и результатов.
- В топографическом SVG N — начало потенциалов; точки A/B/C — концы фазных
  векторов источника, n — потенциал нейтрали. `U_A/B/C` идут N→A/B/C (красные),
  `U_AB/U_BC/U_CA` — B→A/C→B/A→C (зелёные), `U_a/b/c` — n→A/B/C (синие),
  `U_nN` — N→n (жёлтый). Токи `I_A/B/C` и `I_N` начинаются в n.
  Напряжения и токи имеют отдельные явно показанные масштабы. Цвета всех
  диаграмм определены в отдельном файле. Подписи обязательны.
- Результаты одновременно показывают модуль, угол и прямоугольную форму.
- Presets: симметричная, несимметричная, обрыв нейтрали, RLC-нагрузка.
- RU/UK тексты, mobile stacking без горизонтального overflow, локальный расчёт.
- Unit: balanced/unbalanced × ideal/open, finite neutral KCL/Ohm, две конверсии,
  нулевое сопротивление и вырожденный open case. Browser: поля в обе стороны,
  drag, режим, preset, локализация и mobile layout.

Вне первой версии: несимметричный источник, моделирование короткого замыкания,
серверное хранение и URL-сериализация параметров звезды.
