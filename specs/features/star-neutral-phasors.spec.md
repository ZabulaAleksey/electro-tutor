# Несимметричная звезда

Локализованная лаборатория /interactive/star-neutral/ использует соединение Y и один локальный расчёт для диаграмм и числовых результатов. Требования STAR-001–019 мастер-промпта от 23.11.2026 заменяют прежние требования к переключателю Y/Δ, самостоятельному построению и трём выбираемым режимам нейтрали на этой странице. Общая расчётная функция Δ и её численные эталоны сохраняются.

## Источник и ввод

- INT-004 / STAR-014, 016, 017. Название «Несимметричная звезда» / «Несиметрична зірка». Вверху задать симметричный источник ABC (230 В по умолчанию) либо независимые фазные модули и углы. Восстанавливать допустимые сохранённые параметры, включая старый формат звезды. Оригинал прежнего черновика Δ сохраняется, новые изменения записываются в отдельный ключ звезды.
- INT-006 / STAR-002–007, 015. Плоскость Z с равными физическими масштабами отображает R ≥ 0 и оба знака X. Точки A/B/C и компактные фазные поля возле плоскости редактируют одно комплексное значение в омах. Сохраняются полярный ввод, четыре пресета и увеличение участка.
- STAR-008–011. Единственный переключатель нейтрали рядом с плоскостью. При первом включении Z_N = 0, в начале координат появляется точка N. Поля и точка N редактируют то же Z_N. При выключении точка и её поля скрываются, запоминается последнее Z_N. Открытая ветвь имеет нулевую проводимость.
- STAR-012. Использовать единую обработку Pointer Events, захват активного указателя, стабильный масштаб в течение жеста и координаты SVG. Завершать действие на pointerup, pointercancel и потере захвата. На сенсорном экране подпись или точка должны быть доступны при совпадении фаз.

## Расчёт и результаты

- INT-005 / STAR-007, 011, 018, 019. При N = 0 смещение равно нулю. Для открытого провода U_nN = Σ(E_k/Z_k)/Σ(1/Z_k). Для подключённого провода конечного сопротивления применить ту же узловую модель с дополнительной проводимостью 1/Z_N, с численно устойчивым переходом к идеальному проводу. Напряжения нагрузки E_k − U_nN, токи нагрузки (E_k − U_nN)/Z_k и ток нейтрали в направлении n → N удовлетворяют законам Кирхгофа и Ома. Диагностировать недопустимые и вырожденные данные. В поля и результаты не выводить NaN и Infinity.
- INT-007 / STAR-001, 013. На отдельной топографической диаграмме потенциалы N, n и фаз показывать в едином масштабе напряжений. Векторы фазных напряжений источника идут из N, напряжения нагрузки и токи из n, U_AB идёт B→A. Токи имеют собственный масштаб. При размещении надписей учитывать соседние узлы и другие подписи. Для совпадающих узлов сохранить оба обозначения. Числа токов и напряжений показывать в разделе результатов. Самостоятельное построение удалено.
- INT-008. Сохранить симметричный, несимметричный, RLC-пример и пример обрыва. Значения в модели имеют полную точность. Округление показанных чисел не должно менять расчёт.

## Приёмка

Сопоставить исходные кадры №10 (обе диаграммы), №11 (удаляемое упражнение) и №12 (числовой ввод) с новым экраном. Проверить RU/UK, узкий экран, ввод R/X, перетаскивание A/B/C/N, отключение и возврат Z_N, нулевую нейтраль, предельные значения, численные результаты и сохранение после перезагрузки. Сенсорные события браузера и наблюдения на физическом Android фиксируются отдельно.

## Преемственность трёхфазной лаборатории

| Исходный контракт | Действующее требование |
|---|---|
| THREE-LAB-001 | STAR-016. Переключатель Y/Δ удалён. Общая функция расчёта Δ сохраняет свой математический контракт. |
| THREE-LAB-002 | INT-004, STAR-014. Сохранены симметричный и независимый источники, их параметры и восстановление. |
| THREE-LAB-003 | Численные эталоны Δ и закона Кирхгофа действуют для общего вычислителя. Для страницы применяются STAR-011, 016, 018 и браузерный сценарий звезды с переключаемой нейтралью. |
| THREE-LAB-004 | STAR-013. Интерактив самостоятельного построения удалён. Диаграмма рассчитанных величин остаётся частью лаборатории. |
