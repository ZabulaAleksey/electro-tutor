# ElectroTutor — главная и разделы обучения

- FR-407. Двуязычная full-сборка использует единую шапку с логотипом и ссылками на учебник, решения и лаборатории. Главная содержит первый экран и три визуальных входа без каталога. Оформление светлое, подвал компактный.
- FR-408. Учебник выводит опубликованные материалы и действующие связи из метаданных. Раздел решений группирует опубликованные разборы и инженерные демонстрации. RU-only разборы обозначаются как русскоязычные в UK.
- FR-409. Лаборатории и инструменты выводятся из реестров. Каждый самостоятельный эксперимент имеет постоянный адрес. Существующие URL, включая ссылки с фрагментами, сохраняют назначение. Иллюстрации отличаются от моделей.
- FR-410. Preview использует full production build без публикации в production. Действующий контракт публичного RU MVP проверяется отдельно.
- FR-411. Автоматические проверки подтверждают зарегистрированные маршруты, доступность клавиатуры, RU/UK, мобильную вёрстку, отсутствие дублей на главной, работу интерактивов и сохранение PWA.
