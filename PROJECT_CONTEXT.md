# Контекст проекта «Потенциал»

Этот файл — точка входа для нового разработчика или нового чата Codex.
Прочитайте его вместе с `README.md` перед изменением проекта.

## Цель

Двуязычная RU/UA образовательная платформа по электротехнике:

- большой каталог теории и решённых задач;
- три уровня подробности решения;
- формулы LaTeX/KaTeX;
- электрические схемы и векторные диаграммы;
- интерактивные расчётные инструменты;
- SEO для каждой темы;
- услуги репетитора и платные дополнительные материалы.

## Архитектура

- Astro 7, статическая генерация;
- Content Collections + MDX для учебных материалов;
- React Islands только для интерактивных элементов;
- KaTeX для формул;
- Cloudflare Workers Static Assets для публикации;
- Cal.com планируется для расписания консультаций;
- платёжный провайдер пока не выбран.

## URL

Каждая индексируемая страница имеет отдельный языковой URL:

- `/ru/`, `/uk/`;
- `/ru/topics/`, `/uk/topics/`;
- `/ru/topics/dc/mesh-current-method/`;
- `/uk/topics/dc/mesh-current-method/`;
- `/ru/services/`, `/uk/services/`;
- `/ru/interactive/`, `/uk/interactive/`;
- `/ru/contacts/`, `/uk/contacts/`.

## Контент

Материалы находятся в `src/content/lessons/<language>/`.
Метаданные валидируются схемой `src/content.config.ts`.

Каждая тема должна иметь:

- русскую и украинскую версии;
- уникальный `title` и `description`;
- одинаковые `section` и `slug` в обеих версиях;
- список SEO-ключей;
- продолжительность и порядок;
- схемы с прозрачной заливкой;
- три уровня объяснения, если есть решение.

## Дизайн

- светлая и тёмная темы;
- выбор сохраняется в `localStorage`;
- электрические схемы используют семантические цвета, а не `filter: invert()`;
- смысловые цвета токов и напряжений не должны меняться между темами;
- весь текст сохраняется в UTF-8 без BOM, строки — LF.

## Деплой

Cloudflare:

- Node: `22.16.0` или новее;
- Build command: `npm run build`;
- Deploy command:
  `npx wrangler deploy --assets ./dist --name electrotutor --compatibility-date 2026-07-25`;
- Build output: `dist`.

Для корректных canonical URL и sitemap задайте `SITE_URL`.

## Следующие решения

1. Получить точный production URL и записать его в `SITE_URL`.
2. Создать Cal.com и записать ссылку в `PUBLIC_CALCOM_URL`.
3. Выбрать страну/юридическую модель приёма платежей.
4. После этого выбрать платёжного провайдера и реализовать checkout/webhook.
5. Переносить новые темы в Content Collections по единому шаблону.
