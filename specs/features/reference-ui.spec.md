- FR-394: native links/no-JS, keyboard focus, contents, theme persistence и адаптация 320–1920 px. RU/UK copy без автоматической публикации отсутствующего перевода.
- FR-395: unit, check, lint, full/MVP builds; реальные переходы главная→учебник→примеры→редактирование лаборатории; визуальная проверка light/dark desktop/mobile. Старые goldens не обновляются автоматически: смена дизайна явно создаёт ожидаемые расхождения оболочки.

Scope: STANDARD production frontend; существующие Astro components/CSS, без зависимости или API migration. Откат — Git revert. Публикация отдельно.

Приоритет: этот scoped contract заменяет прежнюю композицию первого экрана PAN-001 и палитру UI PAN-005 только для новой главной/общей оболочки.
