# Математические лаборатории ElectroTutor

- FOUR-SHAPE-001. Геометрические пресеты окружности, квадрата, прямоугольника, треугольника и правильного многоугольника формируют исходный контур независимо от выбранного базиса. Номер вершин многоугольника задаётся в диапазоне 3–12.
- FOUR-SHAPE-003. Пользовательский базис допускает линейные комбинации степеней, sin/cos и ступени, заданные по одной функции на строку. Точка параметра отображается из нормированного времени на указанный интервал. Выбор скалярного произведения — равномерное или взвешенное по трапециям. Опциональная нормировка столбцов. Аппроксимация 1D/2D по взвешенному QR без нормальных уравнений. Сообщать об ортогональности, оценке обусловленности и линейной зависимости. Показать сумму компонент и RMS на тех же отсчётах. Черновик пользовательских функций, интервала и весов хранится локально.
- FOUR-SHAPE-002. Отдельную исходную точку можно выбрать, отредактировать или удалить. Сглаживание применяется к исходным точкам за один шаг и входит в отмену. Для открытой траектории сохраняются концы. Сравнение базисов использует одинаковые отсчёты и одинаковый бюджет компонент для одной и той же 1D/2D цели.

Статус: утверждённый прямой user contract2026-10-29. Source — текущий Fourier Sketch read-only; публичный продукт Astro/React/TypeScript, без backend/new dependency. Slice owner ET-LABS-002.

## ET-LABR-013 · Математические лаборатории (№13–17)

- MATH-001..007, 018..019. Пользователь выбирает одну из двух лабораторий. В аппроксимации единый исходный контур передаётся между круговым DFT и существующим подбором многоугольных движений. Круговой метод использует знаковые частоты, комплексные фазы и амплитуды. Многоугольные компоненты описывает масштаб нормированной траектории, поворот, обход и сдвиг. Для каждого метода показывается собственный спектр. Старые ссылки эпициклов ведут в круговой режим.
- MATH-008..011, 020. Компактный выбор объектов, подсказки, доступные кнопки воспроизведения. Остановка возвращает фазу к началу и останавливает часы; сброс фазы сохраняет состояние часов. Файловые действия внизу. Сохраняются существующие локальные конфигурации Фурье и версии JSON опытов; файл конфигурации Фурье и CSV переносят исходные значения без округления. Для того же исходного контура при возврате к методу восстанавливаются настройки и ручной подбор. После изменения контура коэффициенты пересчитываются.
- MATH-012..017. Лаборатория базисов поддерживает аналитические и нарисованные скалярные функции, а также параметрические контуры. При повторном проходе по одному x заменяется ордината. Узлы по x упорядочены; при смене N используется интерполяция. Замыкание применимо к контурам. Ортонормированный DCT-II дополняет DFT, дискретные вейвлеты, Уолша–Адамара и полиномиальные базисы. Сравнение при одинаковом бюджете, RMS/Max и расчёт спектра используют те же отсчёты, что и визуализация.
